# 카피 톤앤매너 가이드

디자인·IA 개편(`docs/audit/P2-design-ia.md` TASK 2)에서 정한 문구 원칙.
새 화면/문구를 쓸 때 이 문서 기준으로 판단한다.

## 원칙

1. **문어체 → 구어체.** "제공합니다", "구성했습니다" 대신 "보여줄게요", "골랐어요".
2. **한 문장 25자 이내.** 길어지면 마침표로 끊는다.
3. **지표 나열 금지, 항상 비교 기준 병기.** 숫자만 던지지 않는다.
   예: "PER 8배" (X) → "PER 8배, 업종 평균보다 낮아요" (O)
4. **금지 표현 규칙은 절대 완화하지 않는다** (CLAUDE.md 표현 규칙 그대로 유지).
   캐주얼함은 말투에서 나오는 것이지, 단정적 추천에서 나오는 게 아니다.
   - "수익 보장", "확정 수익률", "매수하세요", "지금이 기회" 류 금지 — 말투를
     구어체로 바꿔도 이 문구들은 여전히 금지다.
   - 매수·매도 타이밍을 지시하는 문구를 생성하지 않는다.

## 치환 예시

| 이전 | 이후 |
|---|---|
| 오늘의 투자 전략 3가지 | 오늘 볼 만한 거 3개 |
| 종합/저평가 같은 기술적 기준보다, 지금 시장에서 실제로 어떻게 들고 갈지에 맞춘 관점으로 나눴습니다. | 얼마나 오래 들고 갈지에 따라 나눠봤어요. |
| 오늘은 피해야 할 타입 | 오늘은 이런 거 조심 |
| 성과/백테스트 | 우리 성적표 |
| 추천 결과를 주차별로 기록하고, 시간이 지나면서 실제 성과를 공개하는 페이지입니다. | 우리가 뭘 골랐고, 그게 맞았는지 다 까놨어요. |
| 무료에서 검증하고, 프리미엄에서 행동합니다 | 공짜로 확인하고, 확신 들면 구독하세요 |

## 등급 라벨

| 코드 | 이전 | 이후 |
|---|---|---|
| S | 우량 후보 | 지금 봐도 됨 |
| A | 관심 후보 | 좀 더 확인하고 |
| B | 중립·관망 | 아직은 지켜보기 |
| C | 신중 필요 | 조심해야 함 |
| D | 제외 권장 | 지금은 아님 |

정의: `app/lib/grade.js`의 `GRADE_META`. 등급 판정 로직(백분위 계산)은
이 문서와 무관하며 그대로 둔다 — 여기서 바꾸는 건 라벨 문구뿐이다.

## 적용 현황

- `app/lib/grade.js` — 등급 라벨 5개 전체 치환 완료.
- `app/performance/page.js` — h1/설명 문구 치환 완료.
- `app/reports/page.js` — 성과 크로스링크 문구 치환 완료.
- `app/components/home/StrategySection.js`, `AvoidSection.js`,
  `BridgeSection.js` — 표에 있는 제목/설명 치환 완료. 단 이 세 섹션은
  TASK 4(홈 재설계)에서 구조 자체가 통폐합/제거될 예정이므로, 카드 내부
  세부 문구(예: "왜 이 관점에서 보나", "현재 기준으로 이 관점에 맞는
  후보가 충분하지 않습니다")는 TASK 4에서 최종 구조가 정해질 때 함께
  다듬는다.
