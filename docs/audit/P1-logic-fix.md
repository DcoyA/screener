\### 2-1. `update\_data.py`에 추가 계산

\## TASK 4. 성과 페이지 정합성



\### 4-1. 승률 % 부호 제거

"전체 승률 +46.1%" → "전체 승률 46.1%"

"승률 +50.0%" → "승률 50.0%"

승률은 비율이지 증감이 아니다. `grep -rn "승률"` 로 전수 수정.



\### 4-2. 결측 종목 처리

현재 Top10 중 2개가 "데이터 없음"인데 사유가 불명확하다.

\- 결측 사유를 enum으로 기록: `delisted` / `code\_changed` / `fetch\_failed`

\- 화면에 사유 표기

\- 평균 수익률 옆에 표본 수 명시: "전략 평균 수익률 +2.2% (8/10 종목 기준)"

\- 결측률 20% 초과 시 "생존 편향 가능" 경고 배지



\### 4-3. 표본 한계 문구 위치 조정

"평균 초과수익 +10.0%" 큰 숫자 \*\*바로 아래\*\*에

"표본 56주차 · 약 3개월. 통계적으로 확정적이지 않습니다." 를 배치.

현재는 페이지 하단 작은 글씨에만 있다.



\### 4-4. 벤치마크 신선도

`/performance`의 "현재 KOSPI 6,696.96"이 8/25 종가로 보인다.

benchmark 값의 기준일을 화면에 명시하고,

당일 데이터가 없으면 "8/25 종가 기준"이라고 표기.

\## TASK 6. 종목 상세 페이지 재구성



\### 6-1. 현재 문제

\- "한눈에 보는 진단" 섹션이 크롤링 시 헤더만 나오고 본문이 비어 있음

&#x20; (CSR 또는 데이터 결측) → SSR로 전환 필요

\- 정보 순서가 지표 우선 → 초보자 인지 순서와 불일치



\### 6-2. 새 구조

```

① 한 줄 결론 (큰 글씨, 사람 말투)

&#x20;  "지금 사기엔 애매, 6개월 이상 볼 거면 괜찮음"

&#x20;  ← 등급 라벨이 아니라 문장. 등급별 템플릿 + 점수 구간별 변주



② 왜 그렇게 봤나 (3줄, 아이콘 + 비교 기준 필수)

&#x20;  💰 싸다     PER 3.6배 · 같은 업종 42개 중 3번째로 쌈

&#x20;  🛡 안 망함  부채비율 32% · 100% 넘으면 위험 신호

&#x20;  📉 안 오름  최근 3개월 -8% · 같은 기간 시장 +2%



③ 뭘 조심해야 하나 (리스크 + 모델 한계)

&#x20;  지주사라 원래 할인받는 구조. 적정가 계산에서 30% 깎았음.



④ 숫자로 보기 (기본 접힘, 탭으로 전개)

&#x20;  ← 고수용 전체 지표 테이블



⑤ CTA

&#x20;  \[관심종목 담기]  \[리포트에 뜨면 알려줘]

```



\### 6-3. 제거

"이 종목으로 가상매수 체험하기" CTA를 상세 페이지 주 CTA에서 내린다.
