\## TASK 1. 디자인 토큰 확장



\### 1-1. radius 상향 (`app/globals.css`)

```css

\--radius-card: 20px;      /\* 12px → 20px \*/

\--radius-button: 999px;   /\* 8px → pill \*/

\--radius-chip: 999px;

\--radius-input: 14px;

```



\### 1-2. 타이포 스케일 신규

```css

\--font-display: 44px;  --font-display-weight: 900;  /\* 핵심 숫자 1개 \*/

\--font-hero:    30px;  --font-hero-weight:    800;  /\* 섹션 헤드라인 \*/

\--font-title:   20px;  --font-title-weight:   700;

\--font-body:    15px;  --font-body-weight:    400;

\--font-caption: 13px;  --font-caption-weight: 400;

\--line-tight: 1.15;  --line-normal: 1.6;

```



\### 1-3. 섹션 컬러 (CLEO의 탭별 배경색 차용)

```css

\--bg-home:    #f7f5fc;  /\* 라일락 \*/

\--bg-screen:  #eef6ff;  /\* 블루 \*/

\--bg-perf:    #eafff4;  /\* 민트 — 성적표 \*/

\--bg-report:  #fff4ec;  /\* 웜 오렌지 \*/

\--bg-me:      #f5f3ff;

```

각 최상위 라우트의 `<main>` 배경에 적용. 사용자가 색만 보고 위치를 안다.



\### 1-4. 그림자

```css

\--shadow-card: 0 2px 12px rgba(108, 79, 224, 0.06);

\--shadow-lift: 0 8px 24px rgba(108, 79, 224, 0.12);

```

\## TASK 2. 카피 톤앤매너 전환



\### 2-1. `docs/copy-guide.md` 신규 작성

원칙:

\- 문어체("제공합니다", "구성했습니다") → 구어체("보여줄게요", "골랐어요")

\- 한 문장 25자 이내

\- 지표 나열 금지, 항상 비교 기준 병기

\- 단, \*\*금지 표현 규칙(CLAUDE.md)은 절대 완화하지 않는다.\*\*

&#x20; 캐주얼함은 말투에서 나오지 단정적 추천에서 나오지 않는다.



\### 2-2. 치환 예시

| 현재 | 변경 |

|---|---|

| 오늘의 투자 전략 3가지 | 오늘 볼 만한 거 3개 |

| 종합/저평가 같은 기술적 기준보다, 지금 시장에서 실제로 어떻게 들고 갈지에 맞춘 관점으로 나눴습니다. | 얼마나 오래 들고 갈지에 따라 나눠봤어요. |

| 오늘은 피해야 할 타입 | 오늘은 이런 거 조심 |

| 성과/백테스트 | 우리 성적표 |

| 추천 결과를 주차별로 기록하고, 시간이 지나면서 실제 성과를 공개하는 페이지입니다. | 우리가 뭘 골랐고, 그게 맞았는지 다 까놨어요. |

| 무료에서 검증하고, 프리미엄에서 행동합니다 | 공짜로 확인하고, 확신 들면 구독하세요 |



\### 2-3. 등급 라벨

| 코드 | 현재 | 변경 |

|---|---|---|

| S | 우량 후보 | 지금 봐도 됨 |

| A | 관심 후보 | 좀 더 확인하고 |

| B | 중립·관망 | 아직은 지켜보기 |

| C | 신중 필요 | 조심해야 함 |

| D | 제외 권장 | 지금은 아님 |

\## TASK 3. 글로벌 네비 재편



\### 3-1. 5개 항목으로 확정

```

1\. 오늘      /

2\. 종목찾기  /screener

3\. 성적표    /performance   ← 신뢰 증명 = 전환 엔진. 반드시 네비에 노출

4\. 리포트    /reports

5\. 내 종목   /me

```



\### 3-2. 라우트 통합

\- `/search`, `/ranking`, `/risk`, `/final-picks`, `/alternative` → `/screener`로 통합

&#x20; (기존 URL은 301 리다이렉트, 쿼리 파라미터 보존)

\- `/wishlist` → `/me`로 이동 (위시리스트 + 구독관리 + 알림설정 탭)

\- `/premium/reports` → `/reports` 하단 섹션으로 흡수



\### 3-3. 상시 CTA

전 페이지 우측 상단에 오렌지 pill "주 4회 리포트 받기".

CLAUDE.md의 "화면당 오렌지 1개" 원칙에 따라

이 CTA가 있는 화면에서는 다른 오렌지 버튼을 쓰지 않는다.



\### 3-4. 모바일 하단 네비

동일 5개. 현재 "마이페이지 → /wishlist" 불일치도 이걸로 해소된다.
